# Anjan P — Minimalist Portfolio

A clean, minimalist developer portfolio built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS v4**, featuring scroll-triggered animations, section navigation, and dark/light theme support.

## ✨ Features

- **Minimalist Design** — Clean typography using the Geist font and structured whitespace
- **Responsive Layout** — Mobile-first grid layout across desktop, tablet, and mobile
- **Dark / Light Mode** — Instant theme switching with persistent styling
- **Smooth Navigation & Animations** — Side-rail section indicators and IntersectionObserver fade-in transitions
- **Featured Sections** — Hero intro, 6 technical projects (with GitHub & live demo links), thoughts, 5 Coursera certifications (2026), and contact links

## 🚀 Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Geist Font](https://vercel.com/font)

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/AnjanRaj777/minimalist-portfolio.git
cd minimalist-portfolio

# Install dependencies (use --legacy-peer-deps with npm due to React 19 peer dependencies)
npm install --legacy-peer-deps
# or with pnpm:
# pnpm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

## 🏗️ Production Build

```bash
npm run build
npm run start
```
